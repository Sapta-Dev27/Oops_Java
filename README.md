# ⭐ What is Constructor Chaining ?

> **Constructor chaining in Java** means calling one constructor from another.  
> **`this()`** calls a constructor of the **same class**, while **`super()`** calls a constructor of the **parent class**.  
> **`this`** refers to the **current object** and is different from **`this()`**.

---

# ⭐ PRIVATE CONSTRUCTOR — INTERVIEW SUMMARY

> A **private constructor** does not mean an object cannot be created. It means the object **cannot be created directly from outside the class**.  
> The class itself can create the object through a **member/static method** that has access to the private constructor.
